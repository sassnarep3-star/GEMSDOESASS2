Read this before you upload

The honest headline: the expected gain is about +0.008, not a leap. The nine focus sites form a single family whose scores span only 0.2449–0.2778, and the best of them (0.2778) is beaten here by changing exactly one variable — the share of the dot budget that lands inside the mapped fault catalogue, which the metric can only ever score as false positive. Everything else about the prediction is held fixed.

Range-error fix: the primary artifact declares nodata=None with no NaN/inf sentinel anywhere (min 0.0, max 1.0 over the whole array), so a portal range check cannot read a sentinel as out of range. The -nan.tif twin is for GIS inspection only — it intentionally places NaN outside the footprint and fails the stricter whole-array check. Use the primary file.

No file in this repository has ever been scored by DrivenData. The 0.29 is arithmetic on a controlled one-variable extrapolation, and it is labelled MODEL ESTIMATE everywhere it appears. See Why 0.2778 scored for the measurement that produces it.
