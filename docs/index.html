What must pass before a file is released

  • 1. Input trust Organizer-authenticated files plus no template/label leakage anomaly.
  • 2. Feature canary Every feature-alone holdout AUC must be ≤ 0.90.
  • 3. Surface novelty No pinned peer raster may have |rank correlation| > 0.90.
  • 4. Spatial holdout Pooled segment HOLDOUT-DTI must beat the comparable control with a positive paired CI.
  • 5. Final-dot novelty No peer raster may cover >70% of candidate dots within 3 pixels.
  • 6. Strict GeoTIFF One band, template grid, finite [0,1] values, checksum, note, and release selector.
