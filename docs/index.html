Read this before you upload

The honest headline. The nine focus sites form a single family whose scores span only 0.2449–0.2778, and the best (0.2778) won by spending the smallest share of its dot budget inside the mapped fault catalogue — territory the metric can only ever score as false positive. The new file keeps that structural win (zero dots on catalogue) but uses a completely different placement field: damage-zone-edge gradient maxima, which targets blind splays and step-overs missing from the catalogue.

No file in this repository has ever been scored by DrivenData. No score estimate is published for the new file because no organizer truth or holdout is available locally. The first submission response is the only real number.

About the "Predicted values must be in range [0, 1]" error you saw: it arises when any finite cell is outside [0,1]. The primary artifact is zeros mode — nodata=None, no NaN, no infinity, min 0.0, max 1.0 over the whole array — so that error cannot occur by construction. The -nan.tif twin intentionally places NaN outside the footprint and must not be uploaded.
