What changed today

Four experiments, one of them overturned the previous answer

The density law

All nine reported scores fit DTI = C / (0.2N + 0.8(G − C)) with C = 10,950 and G = 51,734, to within ±0.005 (R² 0.903). The corpus is scored by how many cells it spends, not by how well it ranks them. evidence/emission_optimum.json.

The model was the problem

A fitted 125-feature LightGBM looks strong on the catalogue (DTI 0.38) and collapses to 0.192 on a fault compilation it never saw — worse than a space-filling lattice at the same budget (0.295). The more its ranking was trusted (tilt 0 → 1), the worse the transfer. It was overfitting the training label. evidence/emission_controls.json.

One raw band beat the model

Band 19, detrended-elevation slope, separates independently mapped faults from background at AUC 0.757 — the highest of all 19 bands — and a density built only on it reaches 0.403 on the independent target. evidence/sgmc_transfer_auc.json, evidence/feature_tilt_sweep.json.

The honest limitations

  • No organizer score exists for this file. Every historical number on this site is owner-reported; no receipt exists anywhere in the ecosystem.
  • The estimator is a proxy. The 0.403 is DTI against an independent fault compilation, not the hidden truth. Applying the nine-site law to this file gives 0.277 — a tie with the incumbent. The plausible band is 0.18–0.40.
  • Part of the signal is terrain context. Within deciles of detrended elevation, band 19's AUC falls from 0.757 to a weighted 0.636. The design is not purely a fault detector.
  • One seed, one grid. The 300k/σ=5 choice sits on a broad plateau (200k–300k within 0.01 of the peak), but it was selected on the same proxy it is scored on.
  • Three submissions per week. Spending one slot on this file is the whole recommendation; there is no budget to A/B a second variant this week.
