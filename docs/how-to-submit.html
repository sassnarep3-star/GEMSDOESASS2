The steps

1. Download the file above

Use the -zeros.tif variant (or its -zeros.zip). Every file on this site ships as a pair: -zeros.tif (portal-safe) and -nan.tif (a GIS twin with NaN outside the footprint, for visual inspection only). Never submit the -nan.tif.

2. Open the competition submission page

DrivenData — Competition DOE GEMS → Submit. You must be logged in (data page and submissions both require a free account).

3. Choose the file

"File to submit" → pick the single-band GeoTIFF .tif you downloaded (or the .zip containing exactly one GeoTIFF). The portal checks that the CRS, shape and geotransform match the submission format — ours are verified locally against the organizer's own sample_submission.tif grid before publication (11 automated checks, receipt in evidence/final_slopetilt_submission.json).

4. Fill in the name and the note

5. Submit

Weekly cap: 3 submissions per week (Official Rules §3.2). Check the executive summary's verdict block first — only files marked OK TO DOWNLOAD AND SUBMIT have passed the format gate, the uniqueness gate and the holdout gate automatically.

About the error “Predicted values must be in range [0, 1]”

Why it happens. The portal rejects rasters that contain values outside [0, 1] — including NaN cells treated as out-of-range in some upload paths, files with a nodata sentinel (e.g. −3.4e38) written into the data band, or non-float32 output.

How this project prevents it. The shared submission writer (src/gems_sass2/submission.py) emits -zeros.tif with nodata=None and all 12,279,160 cells finite float32 in [0, 1] (0.0 outside the official footprint, 0.0 on all 60,988 mapped catalogue cells) — matching the reference solution's output convention. Checks 09–11 of the 13-check validator enforce this on the saved bytes every time a file is built. If you ever see the error again, you uploaded a -nan.tif twin or a file from another source; use the -zeros.tif from this page.

What the automated validation covers (no human inspection)

  1. file exists, non-empty · 2. single band · 3. float32 · 4. CRS EPSG:32611 · 5. shape 3730×3292 · 6. geotransform exact · 7. footprint 5,167,373 cells · 8. catalogue 60,988 cells · 9. no NaN/Inf inside the footprint · 10. values in [0, 1] · 11. outside-footprint clean · 12. zero on known catalogue · 13. non-trivial predictions

Reproduce: python scripts/fetch_data.py --dest .cache/gems_data then the writer's --validate-only path (or make-equivalent in CI). The uniqueness gate (scripts/uniqueness_gate.py) runs automatically with the build.
