1 · The five steps

  1. Download the file. Use the -zeros.tif (or its .zip). Do not mix the two encodings — see section 3.
  2. Verify the hash. sha256sum gemsass2-hcorr-lineament-offcat-37654-20261031T000000Z-zeros.tif must print 4367b360…f2faf9c1f. If it does not, re-download; do not upload.
  3. Open the submission page at drivendata.org/…/submissions/ (login required) and choose “New submission”.
  4. Attach the file — a single-band GeoTIFF, or a .zip containing exactly one GeoTIFF.
  5. Paste the note above (118 characters, limit 140) and submit. Copy the score the portal returns into this repository — it becomes the first ORGANIZER-CONFIRMED number we have.

Rules on submission counts, from the Official Rules (NLR) §3.2 and §3.4: “You can make multiple submissions, subject to the limits specified on the competition website (three submissions per week)” and “you must select only one set of predictions to use as your final submission.” GenAI use is permitted but “you must indicate in the narrative … the extent to which, if any, you used generative AI technology” (§3.2).

3 · The “Predicted values must be in range [0, 1]” error

Download the -zeros file. That single choice removes the most likely cause.

EncodingOutside the footprintCan it trigger the range error?
-zeros.tif ← ship thisfinite 0.0No. Every byte of the file is a finite value in [0,1], so the check cannot fire on value range.
-nan.tifNaNUncertain. The spec explicitly allows NaN outside the bounds, but the portal's validation is not published; if it applies the [0,1] test to the whole array rather than the footprint, NaN can be rejected. This is the most probable cause of the reported error.

What we can and cannot prove. We could not reproduce the error: the rejected bytes and the portal response were not supplied to this repository, so the cause is a hypothesis, not a diagnosis. Two other documented traps: the official reference notebook writes float64 (the spec asks for float32) and writes no NaN at all; and every top-scoring site file we could pin uses finite values in [0,1] everywhere. Ship -zeros, float32, and the risk goes to zero on value range. Full reasoning with links: knowledge/03.

4 · After you submit

  1. Record the receipt. Paste the portal's returned score into research/ or open an issue. One real number converts every “MODEL ESTIMATE” in this repository into a calibrated observation — it is worth more than another experiment.
  2. Fit the transfer constant. With one ORGANIZER-CONFIRMED point and 40 measured rasters we can finally test which instrument, if any, tracks the hidden test set.
  3. Respect the cap. Three submissions per week per participating entity (Rules §3.2), and a single file must be selected for both prize rounds (§3.4).
