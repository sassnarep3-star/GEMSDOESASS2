Those three points are almost perfectly linear in contamination: −0.001299 DTI per percentage point (R² = 0.998). The slope is negative because the truth set is defined as faults absent from the catalogue, so a dot inside the catalogue exclusion zone can only ever be scored as a false positive.

The candidate changes nothing else. It carries the champion's exact 37,654 dots, sits on the same grid, and is built from an independent geophysical prior. 5 · What would still have to be true for 0.30 to be wrong

  • Downside. If the strain/ridge prior carries no information about expert-identified new faults (only about already-mapped ones), the file degrades to the fitted-law floor of 0.2758 — still at the level of the best focus site, because the dot budget and the catalogue collar were preserved.
  • Upside is capped by the truth mass. A perfect submission cannot exceed TP/(0.2N + 0.8M); the public maximum is 0.4544, so a 0.905 projection is arithmetically available but geologically implausible and is not quoted.
  • Statistical power. The paired bootstrap gives a ratio interval of [0.61, 5.85] on 29 held-out blocks, so “better than the incumbent” is supported at 95.8%, not proven.
  • No organizer receipt. Nothing on this page has been scored by DrivenData. The first submission response will replace the estimate with an ORGANIZER-CONFIRMED value.
