The decisive gate

Why the latest TIFFs are blocked

Against the pinned 13GEMSDOE lattice, HVFD has 37,617 of 37,654 dots within 3 pixels (99.9017%); XGHF has 37,636 of 37,654 (99.9522%). Both exceed the 70% limit. A comparison excluding the lattice cannot override the literal rule.

Only 6,649 footprint cells are farther than 3 pixels from that lattice. At 37,654 distinct dots, even an optimally placed set must overlap at least 31,005 times (82.34%). A smaller budget might avoid this particular mathematical bound, but still requires full uniqueness and holdout validation.

Format is necessary, not sufficient

The two latest research TIFFs pass the conservative local format policy against a hash-pinned owner mirror: one float32 band, matching geometry, no NaNs inside the footprint, all stored values finite in [0,1] and an external validity mask. No organizer acceptance is established. The user's rejected bytes were not supplied, so its error cannot be diagnosed.

How to submit a future approved file

These instructions apply only after all gates and a separate weekly-slot selector approve a new candidate. Nothing currently qualifies.

  1. Verify the run card. Check the surface and final registry scans, feature canaries, same-protocol holdout and 95% CI, saved-byte validation, and selector approval.
  2. Check the live account allowance. Sign in to DrivenData and read the current limit shown on its submission page.
  3. Download the approved file and verify its SHA-256. Use one single-band float32 GeoTIFF or a ZIP containing one TIFF. Match the organizer template's CRS, shape and geotransform; keep predictions in [0,1]. See the official format.
  4. Open New submission. Choose the file, enter the run card's unique note (at most 140 characters under this protocol), and submit. Save the organizer receipt with its exact file hash.
  5. Preserve reproducibility. Retain code, sources, licensing and required generative-AI disclosure under the official rules.

Local validation is not a guarantee of portal acceptance, and a holdout score is not a leaderboard score.
