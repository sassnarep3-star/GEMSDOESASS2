How to make a submission—once authorized

The published competition deadline is December 3, 2026 at 23:59 UTC; confirm the current rules before acting.

  1. Run the frozen lane using the shared prepared features, buffered whole-segment hide-and-recover evaluator and shared writer. Every feature must pass the leakage canary; compare the pooled holdout and paired 95% CI with the best on the same evaluator.
  2. Check the surface before placement and the final dots with python scripts/check_registry.py against the complete current indexed registry; run it once per phase. A missing raster or duplicate stops the check. A separate selector must confirm slot eligibility.
  3. Automatically reopen the exact TIFF and verify its hash, one float32 band, template-matching CRS/shape/transform, finite in-footprint values in [0,1], and the nodata/footprint policy. Run python scripts/check_geotiff.py FILE --sample OFFICIAL_SAMPLE. A local format pass is not organizer acceptance.
  4. Confirm the remaining quota in the authenticated DrivenData submission page. The rules PDF §3.4 says up to three feedback submissions per week; this account's allowance is unknown.
  5. Only when the separate selector approves, download that newly generated TIFF, open DrivenData, select Submit → Make new submission, attach it under File to submit, and paste the run card's unique note (at most 140 characters). Verify the filename and hash before upload.
  6. Save the organizer's score receipt with the file hash, and select one final entry for both prize rounds as required by the rules. Never relabel a projection as a score.
