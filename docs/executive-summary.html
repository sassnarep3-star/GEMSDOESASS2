The lane (lattice) rule

The written rule: a file is a duplicate if more than 70% of its dots fall within 3 px of one registry raster's dots. It is saturated. Dense probability surfaces such as GEMSDOE2 gemsdoe2_turbo_submission.tif (5.17 M positives) cover so much of the footprint that a 22k-dot file can match them at 100%. Earlier audits found this for every top file (evidence). An owner ruling is needed before any file can pass.

Format and submission rules

Single float32 band; values in [0, 1] inside the footprint; NaN or null allowed outside it; EPSG:32611, 100 m, north-up, shape 3730×3292 (problem description ↗). The candidate passes these checks locally (validator output). A format pass is not approval. Submission name and note: submission guide.
