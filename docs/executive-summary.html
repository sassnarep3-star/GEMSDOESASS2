Reproducibility — run the full pipeline locally

git clone https://github.com/sassnarep3-star/GEMSDOESASS2
cd GEMSDOESASS2
# 1. Provide competition data (login-walled, cannot be auto-downloaded):
bash scripts/download_competition_data.sh  # → data/training_features.tif  data/labels.tif  data/sample_submission.tif
python scripts/prepare_data.py
# 2. Generate TTC submission (uses cached external data, no new download needed)
python scripts/generate_submission.py
# 3. Validate (strict-finite, no NaN inside footprint, [0,1], CRS/shape/transform)
python scripts/validate.py docs/downloads/gemsdoesass2-*-zeros.tif
# 4. Check uniqueness vs registry
python scripts/check_uniqueness.py docs/downloads/gemsdoesass2-*-zeros.tif --registry /tmp/GEMSDOE32/registry

Need the data first: the only blocker is data placement — the training pipeline is otherwise GPU-ready and the metric/losses are verified on CPU (see GEMSDOE32’s data/prepared_manifest.json for grid counts).
