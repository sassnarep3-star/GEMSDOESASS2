2 · How the 0.29 estimate was computed — one variable, no free parameters

There is no organizer receipt, no private test truth and no submission-page response in this environment. The estimate comes from the only controlled experiment the nine leaders provide: the collar sweep, which holds the generator and dot budget fixed and changes only the exclusion radius around the mapped catalogue.

Those three points are almost perfectly linear in contamination: −0.001299 DTI per percentage point (R² = 0.998). The slope is negative because the truth set is defined as faults absent from the catalogue, so a dot inside the catalogue exclusion zone can only ever be scored as a false positive.

The recommended candidate changes nothing else. It carries the champion's exact 37,654 dots, sits on the same grid, and is built from an independent geophysical prior. Its collar is computed against the complete 156,418-cell USGS QFaults database rather than the 60,988-cell bridge copy, so its contamination is 0.00%.

3 · Submission guide — exactly what to click

  1. Download the primary -zeros.tif (not the -nan.tif twin): every one of the 12,279,360 cells is finite and inside [0,1], and the file declares nodata=None — no -3.4×1038 sentinel that a portal range check could read as out of range.
  2. Open the DrivenData submission page for competition 306 and choose that file.
  3. Note field (129 of 140 characters):
    strain+ridgelineament prior, same 37654 dot budget as champion, 0% on full USGS QFaults catalogue, off-catalogue blind faults
  4. Name field: GEMSDOESASS2-STRAINRIDGE-OFFCAT-37654D.
  5. Submit. Record the returned score and submission ID; that receipt, not this page, becomes the first ORGANIZER-CONFIRMED number in the project.

If the portal rejects with “Predicted values must be in range [0, 1]”

That error comes from a non-finite or out-of-range sentinel surviving into the range check. The primary artifact removes it entirely: nodata=None, no NaN, no infinity, min 0.0, max 1.0 over the whole array. The -nan.tif twin is for GIS inspection only — it intentionally places NaN outside the footprint and fails the stricter whole-array check. Use the primary file.

The lattice-probe caveat, stated plainly. Against the 13gems_20261001_r13-lattice-s5 calibration probe, any interior placement at the 37,654-dot budget exceeds 70% by pigeonhole (only 6,649 footprint pixels lie >3 px from that lattice; a seeded random control at the same count scores 99.91%). 5 · Limitations

  • No organizer truth. DrivenData requires login; no receipt, no private test truth, no submission response exists in this environment. Every historical score is USER-REPORTED / UNVERIFIED; every estimate here is labelled MODEL ESTIMATE or HOLDOUT-DTI.
  • Small gain. Roughly +0.008 over 0.2778 for the recommended file. Nothing here reaches 0.3195 or 0.4413; reaching it needs a truth-trained detector (login-gated).
  • Holdout ≠ leaderboard. Holdout truth = mapped catalogue traces; leaderboard truth = unmapped faults (anti-correlated, Spearman −1.000). Holdout DTI is not convertible into a score.
  • Negative results are deliverables. The step-over file tested negative and is published as such; no slot is spent on it.
