1.1 Exact Metric Mechanics Governing the +0.0856 DTI Gain (0.1922 → 0.2778)

The official DrivenData Distance-Weighted Tversky Index evaluates prediction $p \in [0, 1]^{\Omega \setminus M}$ against private expert-mapped new faults $G$ (after pixel-exact masking of known USGS/INGENIOUS faults $M$, with $\alpha = 0.2$, $\beta = 0.8$, and triangular kernel $k(d) = \max(1 - d / 300\text{ m}, 0)$): 

TP_w = sum_{g in G} max_{x} [ p(x) * k(||x - g||) ]
FP_w = sum_{x notin M} p(x) * [ 1 - max_{g in G} k(||x - g||) ]
FN_w = |G| - TP_w
DTI  = TP_w / ( TP_w + 0.2 * FP_w + 0.8 * FN_w ) = TP_w / ( 0.8 * |G| + 0.2 * TP_w + 0.2 * FP_w )

Because $\mathrm{TP}_w$ takes a per-truth-pixel maximum $\max_x p(x)k(\|x-g\|)$ whereas $\mathrm{FP}_w$ sums over every predicted pixel, adjacent pixels inside a 300 m disk cannibalize identical $\mathrm{TP}_w$ credit while paying full additive $\alpha = 0.2$ $\mathrm{FP}_w$ tax!
  2. Poisson-Disk Kernel Non-Redundancy (GEMSDOE24 d=1.5 → 0.2477; GEMSDOE25/30 d=2.8 → 0.2600): Thinning H19-5's ribbons into discrete unit dots ($p \in \{0, 1\}$) spaced by $d \ge 2.8\text{ px}$ ($280\text{ m} \approx R$) slashed emitted mass from 121,150 to 44,090 pixels (−63.6% $\mathrm{FP}_w$) while preserving 300 m triangular coverage, adding +0.0678 DTI without changing the underlying classifier.
